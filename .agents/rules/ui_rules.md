# UI Design Rules

## Strict UI Constraints
1. **NO EMOJIS / NO ICONS**: 절대 UI 요소, 버튼, 탭, 타이틀, 뱃지, 리스트 등에 이모지(📈, ⚔️, 📊, 🏢, 🕒, 🤝, 🔥, 🏛️, ⭐️ 등)나 잡다한 아이콘을 넣지 마십시오.
2. 모든 텍스트는 깔끔하고 군더더기 없는 순수 텍스트(Plain Text)로만 간결하게 작성합니다.
3. 푸시하기 전에는 반드시 로컬(`http://localhost:8080`)에서 먼저 확인하도록 하고, 사용자가 명시적으로 승인하기 전에는 절대 `git push`를 실행하지 마십시오.
